# Support

Reup is free/open-source, best-effort software.

There is no paid SLA, guaranteed response time, uptime commitment, or data
recovery commitment. The maintainer may pause, slow, or stop active development
if the project cannot be maintained responsibly.

For help:

1. Check the README and release notes.
2. Run `reup doctor` for local data-health warnings.
3. Search existing issues.
4. Open a focused issue with your platform, Reup version, Claude Code version,
   command run, expected result, and observed result.

Do not include private transcripts, secrets, tokens, or customer data in public
support requests.
